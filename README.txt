予約管理アプリ ローカルOCR版

【GitHub Pagesへの設置】
1. このフォルダの中身を、GitHub Pagesで公開しているリポジトリへアップロードします。
2. index.html と ocr フォルダの位置関係を変えないでください。
3. GitHub PagesのURLを開き、「写真取込」を押します。

【動作】
- 写真は外部AIやOCRサーバーへ送信しません。
- OCR本体と日本語・英語辞書をGitHub Pagesから端末へ読み込み、ブラウザ内で処理します。
- 初回はOCRファイルの読み込みに時間がかかります。
- 読み取り結果は必ず確認・修正してから入力フォームへ反映してください。
- 手書き、傾き、影、低解像度、複雑な表は誤認識しやすくなります。

【撮影のコツ】
- 用紙を平らに置き、真上から撮影します。
- 書類全体を画面いっぱいに写します。
- 影や反射を避け、文字へピントを合わせます。
- iPhoneでHEICが読み込めない場合は、スクリーンショットまたはJPEGで試してください。

【重要】
OCR結果の正確性は保証されません。婚礼日、人数、アレルギー、ケーキサイズなどは、原本と照合してください。
